# 社区行为准则

[English](../../CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT.md)

## 我们的承诺

我们承诺为所有参与 BSWorld 社区的人提供不受骚扰的环境，不因年龄、体型、可见或不可见的残障、民族、性别特征、性别认同和表达、经验水平、教育程度、社会经济状况、国籍、外貌、种族、阶层、肤色、宗教、性身份或性取向而区别对待。

我们将以有助于建设开放、友好、多元、包容和健康社区的方式交流与协作。

## 行为要求

有助于形成良好社区环境的行为包括：

- 对他人保持同理心、耐心和尊重；
- 尊重不同的观点、经历和技术方案；
- 提出并接受有建设性的技术反馈；
- 对错误负责，及时修正并从中学习；
- 围绕项目本身和整个社区的共同利益展开讨论。

不可接受的行为包括：

- 使用带有性暗示的语言或图像，或者进行不受欢迎的性关注与接触；
- 挑衅、侮辱、贬损性评论，以及针对个人或政治立场的攻击；
- 公开或私下骚扰他人；
- 未经明确许可公开他人的私人信息；
- 威胁、恐吓、蓄意扰乱讨论或持续以恶意方式参与；
- 其他在专业环境中通常会被认为不恰当的行为。

## 适用范围

本准则适用于项目仓库、Issue、Pull Request、代码审核、讨论区、聊天频道、活动，以及由项目管理的其他交流空间。任何人以 BSWorld 官方代表身份参与公开活动时，也应遵守本准则。

## 举报与处理

如遇辱骂、骚扰或其他不可接受的行为，请发送邮件至 [menglingao@xiaomi.com](mailto:menglingao@xiaomi.com)，私下联系项目维护者。请勿在公开 Issue 中披露个人信息或其他敏感细节。

项目维护者会公平审查举报，保护举报人的隐私和安全，并根据具体情况采取适当措施。维护者可以编辑或删除违反本准则的评论、提交、代码、Issue 和其他贡献。根据行为的严重程度及是否重复发生，处理措施可以包括私下纠正、正式警告、临时限制参与或永久移出项目交流空间。

负责处理举报的人如存在利益冲突，必须主动说明并退出该事件的处理。对举报人或调查参与者进行报复，同样属于违反本准则的行为。

## 来源说明

本准则基于 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 调整而成，其中的社区影响处理方式参考了 [Mozilla 行为准则处理阶梯](https://github.com/mozilla/diversity)。
